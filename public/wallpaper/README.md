# AE動態桌布（PWA 原型）

網址：`/wallpaper/`（互動模式直達：`/wallpaper/?mode=play`）

iPhone 用 Safari 打開 → 分享 → 加入主畫面，即可像 App 一樣全螢幕使用。所有作品只存在使用者手機（IndexedDB / localStorage），不會上傳。

## 功能
- 匯入照片當底圖（自動裁成 1080×2340）
- 編輯：手寫字、手畫光紋（會流動發光）、文字方塊、可愛符號庫（愛心、月亮、太陽、星星、無限、花、樹、鳥、魚、狗、貓…）、匯入可愛圖片；拖曳移動、雙指縮放旋轉、復原
- 動態可愛元件 ×3：雲朵寶寶、跳跳星、果凍愛心（點擊會動＋發聲）
- 可愛音效 ×3（即時合成，無版權問題）：啵啵泡泡、叮叮鈴鐺、啾啾小鳥；每種元件可各自挑聲音
- 動態濾鏡 ×3：蜜桃奶霜、夢幻紫霧、復古底片
- 動態主題 ×3：夜店雷射、微風流動、閃閃發光（匯入音樂後跟著節奏變化）
- 匯入音樂
- 互動模式：全螢幕＋鎖定畫面時鐘預覽、觸碰特效、AE 互動按鈕（可隱藏，長按畫面叫回）
- 鎖定畫面按鈕：透過 iOS 18 鎖定畫面控制項＋捷徑「打開 URL」叫出互動模式
- 桌布更新頻率：每 N 小時／天，從「我的桌布收藏」輪播
- 匯出：靜態 PNG、動態影片（MP4/WebM，含音樂與音效）

## iOS 限制
- 任何第三方 App 都無法在背景自動更換系統桌布；可用 iOS「相片隨機顯示」（每小時／每天）或捷徑自動化搭配。
- 系統桌布只能是靜態圖或 Live Photo；匯出的影片需轉成 Live Photo。動畫與音效完整呈現於 App 的互動模式。

## 檔案
- `js/app.js` 介面與互動、`js/scene.js` 場景繪製與存檔、`js/effects.js` 濾鏡／主題／元件／粒子、`js/sound.js` 音效與音樂、`js/store.js` 本機儲存、`sw.js` 離線快取
