# AE Lumina Wall｜光之牆 — 開發紀錄與驗收（PV）

產品定位：AE Universe Creation 的數位藝術精品展演服務。低調奢華、單純專注、讓人沉浸在作品裡。
網址（部署後）：`/gallery`（檔案 `public/gallery.html` + `public/gallery/*`）

## R1（2026-11-20）— 第一個穩定可執行版本 ✅

### 功能
| 區塊 | 內容 |

### 驗收（PV）— 自動化
`tests/gallery.smoke.mjs`（Playwright），三種螢幕各跑一次：桌機 1440×900、iPhone 13 直式、電視 1920×1080。
檢查：27 幅渲染、無橫向捲動、選取順序、上傳＋自動選取、設定面板、直式作品完整可見且佔滿 ≥84%、六種轉場皆完成且結束後作品完整不透明無遮罩、暫停、動畫幀率、Esc 關閉、重新整理後上傳與選取仍在、零 console 錯誤。
R1 結果：**72/72 通過**。

執行方式：
```
cd public && python3 -m http.server 8765 &
node tests/gallery.smoke.mjs http://localhost:8765 ./shots
```

### 已知限制（R1）
- iPhone Safari 不支援網頁全螢幕 API：以全畫面覆蓋呈現（加到主畫面後可無網址列）。
- iPhone 靜音鍵開啟時，網頁生成音樂可能無聲（iOS 系統行為）。
- 上傳作品只存在該台裝置的瀏覽器，尚未雲端同步。
- 官網選單尚未加入「光之牆」入口（依 RELEASE_GUARD 規範，改動全站導覽需 Owner 同意）。

### AE 工作室（隱藏入口）
- 客戶看不到「加入作品」「拖曳加入」「上傳音樂」「移除作品」。
- 進入方式：**長按左上角三環標誌 3 秒 → 輸入工作室密碼**。關閉瀏覽器分頁後自動鎖回；工具列也有「鎖定」。
- 密碼不存在程式碼裡（只存加鹽的 PBKDF2 雜湊）。密碼只交給 Owner，不寫進任何檔案。
- 限制：R2 的驗證在瀏覽器端，屬「防一般人」等級；工作室加入的作品只存在該台裝置。R3 改為伺服器驗證＋雲端作品庫。

## R3（2026-11-21）— AE 雲端作品庫＋完整展覽功能 ✅

### 雲端作品庫（AE 工作室）
- 工作室密碼改由**伺服器驗證**（`api/lumina.js`，密碼只存在 Vercel 環境變數 `LUMINA_STUDIO_PASSWORD`）；登入 12 小時有效，換密碼即全部失效。R2 寫在瀏覽器裡的密碼雜湊已移除。
- AE 在工作室加入的作品（圖片、GIF、影片）與 AE 曲目存到 **Vercel Blob（私有）**，所有客戶裝置同步。
- 作品資料：中英文標題、年份、媒材、尺寸、中英文作品說明、對客戶隱藏。館藏 27 幅也可編輯（刪除時改為隱藏）。
- 排序（往前／往後）、刪除、影片自動擷取封面。
- 設定步驟見 `ops/LUMINA_SETUP.md`（Owner 需在 Vercel 設定密碼並確認 Blob）。

### 靜態展覽
- **作品賞析**：單幅全螢幕細看，雙擊／滾輪／雙指縮放、拖曳移動，右側（手機在下方）展簽：標題、年份・媒材・尺寸、作品說明；可左右切換，一鍵從這幅開始展演。
- **數位畫框模式**：每幅停留可設 4 秒到 1 小時（電視、大廳長時間掛一幅）。
- **作品說明卡**：展演時標題下顯示年份・媒材與作品說明（美術館、線上展覽模式預設開啟）。

### 動態展覽
- **展覽（策展清單）**：工作室把選取的作品存成展覽，含中英名稱、展覽說明、場景模式；作品牆上方出現展覽分頁，客戶點選即切換並套用該展覽的模式。
- **單幅設定（像 PowerPoint）**：在展覽中，每幅可個別指定停留秒數與轉場。
- **動態作品**：MP4／WebM／MOV 影片與 GIF 動畫可在展演中播放；影片較長時會播完再換下一幅。
- **作品列**：展演中可叫出縮圖列，直接跳到任何一幅（鍵盤 T）。
- **鏡頭漫遊**：緩慢推近並遊走於畫作細節（私人宅邸模式預設開啟，其他模式可在設定開啟）。
- **展演連結（電視／大廳一鍵開播）**：複製連結 `…/gallery?show=<展覽>&mode=<模式>&autoplay=1`，在電視或任何裝置打開即出現「輕觸開始展演」；被隱藏的作品不會出現在客戶的連結中。
