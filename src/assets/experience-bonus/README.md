# AE Experience Bonus Wallpapers (preview/20261106-experience)

## Design
- **Free wallpaper**: each experience’s own result card / tall phone wallpaper (Touch Moment uses hi-res `experience-hires`; Color Moment saves the Lightprint Card). Never gated on share/follow.
- **Bonus (exclusive, more attractive than free)**:
  1. **Hi-res texture close-ups** — crop of an existing AE artwork’s detail area, original pixels only, resized to 1080×1920. No AI, no filters on the paint.
  2. **Lightprint-exclusive edition** — portrait fit of an existing AE artwork + **overlay-only** soft gold frame / vignette / glow. The painting underneath is not filtered or redrawn.
